# DMart Sales & Profit Dashboard

## Project Overview
Developed an interactive Excel dashboard to analyze DMart's sales and profit performance across regions, cities, product categories, years, and customer types. The project focuses on identifying sales trends, evaluating profitability, and generating insights to support business decision-making.

## Objectives
- Analyze overall sales, profit, quantity, and order performance.
- Compare sales and profitability across regions and cities.
- Identify high-performing product categories.
- Understand customer purchasing patterns and payment methods.
- Track sales trends across different years.

## Tools & Technologies
- Microsoft Excel / WPS Spreadsheets
- PivotTables and Pivot Charts
- Excel formulas and functions
- VLOOKUP, XLOOKUP, INDEX-MATCH
- SUMIFS, COUNTIFS, IFERROR
- KPI cards, charts, and data visualization

## Key Features
- **KPI Analysis:** Tracks total orders, sales, profit, and quantity.
- **Regional Analysis:** Compares sales performance across regions.
- **Category Analysis:** Evaluates sales, profit, and profit margins by product category.
- **City Analysis:** Compares business performance across cities.
- **Customer Analysis:** Examines sales and profitability by customer type.
- **Payment Analysis:** Analyzes orders, sales, and profit by payment method.
- **Dashboard Visualization:** Presents key metrics and trends through charts and visual elements.

## Key Learnings
- Practiced data analysis using Excel formulas and lookup functions.
- Developed skills in summarizing data using PivotTables.
- Learned to transform raw sales data into meaningful business insights.
- Improved dashboard design and data visualization skills.

## Conclusion
This project demonstrates the use of Excel for sales analysis, performance monitoring, and business reporting. It showcases practical data analysis skills through structured calculations, visualizations, and dashboard development.
